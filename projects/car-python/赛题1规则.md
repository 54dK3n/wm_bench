# 广阳岛机器人比赛评分规则

Python 和 Blockly 两个项目采用相同评分规则。每个任务满分 100 分，最终成绩以后台重新计算并保存的分数为准；模拟器中的实时评测分数仅供参考。

## 一、总分组成

| 评分项目   | 满分   |
| ---------- | ------ |
| 任务完成分 | 40 分  |
| 规则分     | 25 分  |
| 自主运行分 | 15 分  |
| 效率分     | 20 分  |
| 合计       | 100 分 |

计算公式：

```
单次成绩 = 任务完成分 + 规则分 + 自主运行分 + 效率分
```

最终成绩保留一位小数，最低 0 分，最高 100 分。

## 二、任务完成分：40分

每张地图中的目标物、混淆物、导航点、指定障碍物和返回起点均算作一个任务单元。

```
任务完成分 = 40 × 已完成任务单元数 ÷ 总任务单元数
```

### 任务1

| 内容               | 数量 |
| ------------------ | ---- |
| 按顺序经过导航点   | 4个  |
| 把目标物送到目标点 | 1个  |
| 把混淆物移出道路   | 1个  |
| 避开指定障碍物     | 1个  |
| 完成任务后返回起点 | 1个  |
| 总任务单元         | 8个  |

每完成一个任务单元得5分。

### 任务2

| 内容               | 数量 |
| ------------------ | ---- |
| 按顺序经过导航点   | 6个  |
| 把目标物送到目标点 | 2个  |
| 把混淆物移出道路   | 2个  |
| 避开指定障碍物     | 2个  |
| 完成任务后返回起点 | 1个  |
| 总任务单元         | 13个 |

按完成比例计算，共40分。

### 任务3

| 内容               | 数量 |
| ------------------ | ---- |
| 按顺序经过导航点   | 8个  |
| 把目标物送到目标点 | 3个  |
| 把混淆物移出道路   | 3个  |
| 避开指定障碍物     | 3个  |
| 完成任务后返回起点 | 1个  |
| 总任务单元         | 18个 |

按完成比例计算，共40分。

### 任务判定细则

1. 导航点必须按照编号顺序经过。提前经过后面的导航点不计分，需要在完成前一个导航点后重新经过。
2. 目标物必须完整放入对应的绿色目标点。程序结束时如果目标物又离开目标点，该项不计分。
3. 混淆物必须完整离开道路，并与道路边缘保持系统规定的 2.5 厘米安全距离。
4. 指定障碍物必须全程避开。碰撞指定障碍物后，该障碍物的任务分永久丢失，本次运行不能判定为全部完成。
5. 返回起点必须在目标物、混淆物和全部导航点完成后才会生效。提前经过起点不计入最终返回。
6. 避障任务分会在其他任务目标完成后统一确认，因此运行过程中可能暂时看不到该项得分。

## 三、规则分：25分

每次运行初始规则分为25分。

| 违规行为     | 扣分       |
| ------------ | ---------- |
| 每次驶出道路 | 2.5分      |
| 在道路外停留 | 每秒0.42分 |
| 每次发生碰撞 | 1.7分      |

计算公式：

```
违规扣分 =
驶出道路次数 × 2.5
+ 道路外累计时间 × 0.42
+ 碰撞次数 × 1.7

规则分 = 25 - 违规扣分
```

规则分最低为0分。

补充说明：

- 是否驶出道路按照整辆车的轮廓判断，不只是判断小车中心点。
- 小车驶出道路后重新进入，再次驶出会算作新的驶出道路事件。
- 连续多次向障碍物移动并触发碰撞，可以被记录为多次碰撞。
- 碰撞指定障碍物时，既会扣规则分，也会失去对应的避障任务分。
- 当前不设置超速扣分。
- 当前不设置逆行、红灯和禁行区规则。

## 四、自主运行分：15分

程序完全自主运行，得15分。

运行过程中如果使用人工方式直接干预小车，本项扣15分，最低为0分。

Blockly项目没有人工驾驶入口，正常使用积木运行时通常获得15分。Python项目使用程序中的传感、规划和道路控制指令不属于人工干预。

## 五、效率分：20分

只有完成全部任务单元后，才计算效率分。

| 完成时间       | 效率分         |
| -------------- | -------------- |
| 120秒以内      | 20分           |
| 120秒至600秒   | 按时间逐渐降低 |
| 600秒及以上    | 0分            |
| 未完成全部任务 | 0分            |

120秒至600秒的计算公式：

```
效率分 = 20 ×（600 - 完成时间）÷ 480
```

如果碰撞了必须避开的指定障碍物，任务无法全部完成，因此效率分为0分。

## 六、计算示例

任务1全部完成，用时150秒；驶出道路1次，在道路外停留2秒，没有碰撞，也没有人工干预：

```
任务完成分：40分

违规扣分：
2.5 + 2 × 0.42 = 3.34分
规则分：21.7分

自主运行分：15分

效率分：
20 ×（600 - 150）÷ 480 = 18.8分

最终成绩：
40 + 21.7 + 15 + 18.8 = 95.5分
```

## 七、正式成绩和队伍总分

- 只有用户点击“正式提交”的记录才进入正式比赛记录。
- 普通运行或仅保存的记录不进入正式排名。
- 每个任务单次满分为100分。
- 同一队伍可以有多个用户名。
- 后台分别取该队伍所有成员在任务1、任务2和任务3中的最高正式提交成绩。
- 队伍三项总分为三个任务最高分之和，满分300分。
- 不计算平均分，也不会因为提交次数较多而额外加分。
- 页面显示的实时评测仅供参考，正式成绩以后台保存并重新计算的结果为准。
