## 2. 现在的“仿真视觉”不是真正的视觉

这是我看代码之后认为**最需要改的地方之一**。

现在仿真模式的：

```python

robot.sees("包裹")
robot.distance_to("包裹")
```

实际上不是通过摄像头画面识别。

代码里面是直接拿：

```text
机器人坐标
目标物坐标
机器人朝向
```

算出目标是不是在视野里。

本质上是：

```text
系统知道橙子坐标
        ↓
判断橙子在不在车前面
        ↓
直接告诉 Python：看见橙子
```

这样教学演示没问题。

**但是用于复赛不够。**

因为赛规明确把环境感知、图像识别、路径规划、自主决策列为考察能力。

复赛如果参赛者写：

```python
if robot.sees("橙子"):
    ...
```

而系统直接从场景对象标签告诉他“这里就是橙子”，实际上相当于给了答案。

```text
        ↓

        ↓
Python / JS CV
        ↓

```

这样才真正叫：

**感知 → 决策 → 控制。**

而且你现在项目已经带：

```text
ONNX Runtime

vision.js
```

这部分架构基础已经很好。

# 5. 最大的“正式比赛”风险其实不是 3D，而是安全性

这个项目现在是：

> **纯静态前端。**

也就是说：

```text
index.html
app.js
python-worker.js
vision.js
Three.js
Pyodide
```

全部下载到参赛者浏览器。

这用于教学非常好。

但是正式比赛会有一个严重问题：

### 参赛者可以打开 F12。

然后：

```javascript
missionAttempt.completed = true
```

或者直接修改：

```javascript
score = 60
```

甚至可以改场景里的：

```javascript
activeMission.goal
activeMission.obstacles
robotPose
```

所以：

> **现有项目不能让浏览器成为最终成绩的可信来源。**

这个一定要改成：

```text
             ┌─────────────┐
             │ 比赛服务器   │
             │ 权威评分     │
             └──────┬──────┘
                    │
        websocket / HTTPS
                    │
┌───────────────────▼─────────────────┐
│             浏览器仿真器              │
│ Three.js + Python IDE + 视觉          │
└─────────────────────────────────────┘
```

浏览器负责：

- 写程序
- 显示 3D
- 运行仿真

服务器负责：

- 队伍身份
- 赛题
- 随机种子
- 比赛开始时间
- 提交次数
- 运行日志
- 评分确认
- 最终成绩
- 排行榜
- 防篡改

这是从“教学平台”变“比赛平台”的关键一步。

# 6. 复赛第二部分其实可以和你的仿真器深度绑定

这点反而非常适合你这个项目。

赛规规定讲解视频应基于**本队真实仿真运行录像**，讲任务、程序、算法、路径规划、控制策略、运行结果、失败原因等；AI 问答也可以围绕仿真结果和算法设计出题。

而且评审还可以要求：

- 原始仿真录像
- 程序截图
- 运行日志
- 源代码片段



所以我强烈建议你从现在开始就在仿真系统里设计一个：

### `RunRecord`

每次正式运行自动保存：

```text
运行编号
队伍编号
赛题编号

Python 源代码
随机种子
开始时间
结束时间

每 100ms：
    x
    y
    heading
    speed
    steering
    camera frame id

事件：
    到达任务点
    红灯
    压线
    碰撞
    抓取
    放置
    到达终点

最终：
    分数
    用时
    违规记录
```

这样以后可以直接生成：

### 仿真回放

不用真的录整个屏幕。

例如：

```text
RunRecord.json
       ↓
ReplayPlayer
       ↓
100% 重现参赛者比赛
```

甚至复赛的 AI 问答可以自动问：

> 你在 01:24 时为什么选择右转？

> 你的车辆在第三个路口发生一次越线，请分析原因。

> 你的程序中第 36 行采用什么方式处理红灯？

这样这个比赛的特色会非常强。
