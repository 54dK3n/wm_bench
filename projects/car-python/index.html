在编辑器里直接写 robot… 即可：运行器会自动等待每条小车指令完成，返回值可直接赋给变量，不需要手写 await。导航传感器提供任务道路锚点、真实任务进度、当前抓取物的安全投放预览、相对里程、当前道路局部状态与不含坐标的道路拓扑，六类查询每次程序合计最多 1000 次；道路控制只执行学生程序指定的短程循路或当前出口。系统不会寻找路口、选择出口、自动绕障或规划路线。虚拟车载摄像头只返回当前画面中的类别、方位、估算距离与置信度，各接口都不会提供目标物、混淆物或障碍物的地图坐标。

            

              
robot.odometry()读取相对本次程序起点的 forwardCm、rightCm、headingDeg、累计 distanceCm 和仿真 tick。航向为正表示左转，为负表示右转。pose = robot.odometry()

              
robot.mission()仅用于正式广阳岛场次。返回 schemaVersion、mapId、mapVersion 及当前服务端冻结地图的公共任务锚点：start、storage、按顺序的 checkpoints、return。普通单局另返回 objects：目标物、混淆物、障碍物各自的 role、roadId 与 progressCm，供程序做路线规划后再用摄像头确认；不返回任何世界坐标、朝向、推荐出口或规划路线。练习/筛选私有布局的 objects 固定为空。mission = robot.mission()

              
robot.task_state()仅用于正式广阳岛场次。返回 schemaVersion、completed、total、status、nextCheckpointId、targetDelivered、distractorCleared、avoidanceStatus、goalReached 和 tick。抓取或释放后应重新读取它确认任务引擎是否真正计分。progress = robot.task_state()

              
robot.release_preview()仅用于正式广阳岛场次且夹爪持有物体时。预览按当前车头方向立即 release的结果，返回 holding、releaseAccepted、releaseReason、wouldCompleteDelivery、roadClearanceCm、requiredRoadClearanceCm 和 tick。混淆物只有 releaseAccepted 和 wouldCompleteDelivery 都为 True 才应释放；它不返回预落点坐标、对象编号或道路名称。preview = robot.release_preview()

              
robot.road_state()仅用于广阳岛。返回 onRoad、roadId、roadIds、lateralOffsetCm、headingErrorDeg、leftClearanceCm、rightClearanceCm、frontClearanceCm、roadProgressCm、fromNodeId、toNodeId、atNode、nodeId、atJunction、junctionId、exits 和 tick。frontClearanceCm 是车头正前方 500 cm 内的碰撞余量，量程内没有碰撞边界时为 None；atNode 为 True 时，可从 exits 中自行选择一个 roadId 交给 take_exit。每个出口只含 roadId、direction 和 turnDeg，方向为 left、straight、right 或 back，转角左正右负；列表包含全部合法出口，不代表系统推荐。roadId 在离路时表示最近道路；横向偏移为正表示偏右、负表示偏左；两侧余量按车体边缘计算。onRoad 为 False 时不要依赖余量继续前进。road = robot.road_state()

              
robot.map_graph()读取广阳岛的无坐标道路拓扑。返回 schemaVersion、nodes 和 edges：节点只含 nodeId、roadIds，道路只含 roadId、fromNodeId、toNodeId、lengthCm、oneWay。它不会返回地图坐标、任务物体、推荐出口或规划路线，也不会让小车移动；路线仍由程序自行选择。graph = robot.map_graph()

              
robot.follow_road(100, 40, True)让小车沿当前道路短程居中行驶；距离 maxCm 可设 10～500 cm，speed 可设 10～100，表示期望速度占车辆最高速度的百分比。第三个参数 obey_speed_limit=True 时，道路控制会在每个仿真 tick 按冻结道路和限速区自动钳制实际速度；当前任务不设置超速扣分。它不会寻找路口、选择出口、绕障或规划路线。遇到路口、道路端点、前方障碍或道路边界会先停车。返回 accepted、stoppedBy、roadId、distanceCm 和 elapsedTicks；常见停止原因是 max_distance、junction、road_end 或 front_clearance。两项道路控制合计每次程序最多 300 次。比赛会把每次调用作为一个完整动作执行和记账；如需边走边观察，请减小 maxCm 并分多次调用。极少数弯曲路口可能停在判定半径的浮点边界外：若返回 junction 但紧接着读取的 atJunction 仍为 False，只执行一次 robot.forward(2) 前探并重新读取 road_state()，确认后再调用 take_exit，不要盲目循环前进。result = robot.follow_road(100, 40, True)

              
robot.take_exit(road_id, speed=30, obey_speed_limit=False)只在当前道路节点执行学生从 road_state()["exits"] 中选定的 roadId，转入该相邻道路后立即停车。speed 为 10～100 的期望速度百分比；obey_speed_limit=True 时每个仿真 tick 都按冻结道路和限速区自动钳制实际速度。返回 accepted、stoppedBy、roadId、distanceCm 和 elapsedTicks；成功进入时 stoppedBy 为 entered_road，不在节点、出口无效或方向不允许时会明确拒绝。它不会寻找路口、替学生选择出口、绕障或规划路线。result = robot.take_exit(road_id, 60, True)

              
robot.observe("目标物")返回同一摄像头帧中已稳定的识别列表；第二个置信度参数可设 0～1，默认 0.6。每项固定包含 category、categoryLabel、name、label、direction、distanceCm、confidence、near 和 stable；距离无法估算时 distanceCm 为 None。类别可替换为障碍物、混淆物、存放点或清理点，也可省略类别读取全部支持对象。objects = robot.observe("目标物", 0.6)

              
robot.approach("目标物", 100)按摄像头结果实际小步转向和前进；第二个参数是 5～200 cm 的目标估算距离，省略时以安全接近状态为准，第三个 max_steps 可设 1～100。安全到达返回 True，未识别、画面不稳定、遇到障碍或用完步数返回 False。可用于目标物、混淆物、存放点或清理点；障碍物仍应由程序自行规划路线绕开。ok = robot.approach("目标物", 100)

              
robot.holding()返回夹爪当前持有的“目标物”或“混淆物”；夹爪为空时返回 None。print(robot.holding())
