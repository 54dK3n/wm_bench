# 识物工坊

一个受 Teachable Machine 启发的浏览器端橙子识别训练与竞赛平台。参赛模型固定使用“橙子”和“非橙子”两个类别，用户可以上传图片或使用摄像头采集样本，在设备本地训练、测试并导出 TensorFlow.js 模型包。

## 功能

- 固定“橙子 / 非橙子”二分类数据集与全部样本管理
- 摄像头单张/连续采集
- MobileNet V2 特征迁移学习与可取消训练
- 上传图片或摄像头实时预测
- IndexedDB 当前设备浏览器自动保存
- 项目 ZIP 备份与恢复
- `model.json`、`weights.bin`、`metadata.json` 模型 ZIP 导入导出
- 统一竞赛平台账号与队伍、最后一次模型提交、保密测试集自动评分与分组排行榜
- 响应式中文界面与键盘/读屏支持

后台成绩采用均衡准确率：`（橙子识别正确率 + 非橙子排除正确率）÷ 2`。本项目训练的是整张图片分类模型，不是会绘制物体边界框的目标检测模型。图片、样本和训练过程默认只保留在用户设备中。

## 统一平台接入

正式比赛由辰龙竞赛统一平台负责注册、登录、队伍、分组和管理员权限。统一网关向识物工坊转发短时有效的 `x-chenlong-platform-principal` 签名身份，识物工坊使用 `PLATFORM_SSO_SECRET` 校验，受众固定为 `workshop`：

- 普通用户按中央队伍 ID 同步为识物工坊队伍；统一平台使用小学组、初中组和高中组三个组别。旧版 `primary_low`、`primary_high` 身份及 D1 数据会兼容读取并规范为小学组，不拆分成绩。
- 若识物工坊已有规范化名称相同的旧队伍，会复用旧队伍及其历史提交，不创建同名重复队伍。
- 统一平台管理员可以直接进入识物工坊管理台，不再设置第二套管理员密码。
- 没有统一平台身份头时，服务端仍兼容已有的队伍和管理员 Cookie，便于旧部署平稳迁移；有签名头但签名错误、受众不符或已经过期时不会回退旧 Cookie。
- 退出统一调用 `/api/v1/auth/logout`；训练台、提交端和管理台分别返回统一 `/portal.html` 或 `/admin.html`。

`PLATFORM_SSO_SECRET` 必须与统一网关一致，并至少包含 32 个 UTF-8 字节。不要将实际密钥提交到仓库。

训练项目、样本图片和本地模型不会随统一账号上传，仍保存在当前设备的浏览器 IndexedDB 中。公共设备使用完毕后应清理站点数据；需要跨设备继续时请导出项目 ZIP。

## 容量与评分稳定性

- 统一平台账号容量为 **2,000**，识物工坊按 **500 人同时在线**设计。
- 统一平台队伍只在首次关联、改名或分组变化时写入识物数据库；普通刷新不会重复写 D1。首次同步写入通过容量为 2,048 的单写者 FIFO 排队，避免大量同时登录造成 SQLite 写冲突。
- 模型文件和提交记录先可靠写入 R2/D1，再进入后台评分队列。评分队列固定 2 个并行工作槽、最多保留 4,096 个唯一任务，同一“提交编号 + 测试集版本”的浏览器重试只执行一次。
- 测试集按组别、版本和对象键缓存 10 分钟；同一版本的并发评分共用一次 R2 读取与格式校验。
- 管理员替换测试集后，已有队伍的最后一次提交会批量标记并在后台重新评分，不再阻塞上传请求。服务中断后，选手再次打开提交页或管理员刷新概览会自动恢复未完成任务。
- `GET /api/competition/health` 返回评分队列、缓存和容量状态，便于比赛前检查。

识物工坊的 Cloudflare D1/R2 本地绑定由统一平台启动器提供。正式联调应从统一网关进入；网关将识物上游连接限制为 128 并复用连接，为 Vite/Miniflare 提供背压。不要把 Vite 预览端口直接暴露给大量用户，也不要单独用不含 D1/R2 绑定的 Node 静态运行方式代替统一启动器。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。摄像头仅在 HTTPS 或 localhost 环境可用。

直接启动识物工坊时可以继续使用已有本地 Cookie；完整统一登录流程需要从竞赛统一平台入口访问。

## 验证

```bash
npm run lint
npm test
```

完整测试包含 500 个 FIFO 工作、500 支不同队伍首次同步、500 次共享测试集读取以及提交幂等性等容量检查。所有容量测试使用隔离的临时数据，不读取或改写正式比赛 D1/R2。

## 技术栈

React 19、vinext/Vite、TensorFlow.js、MobileNet、IndexedDB、JSZip 与 Cloudflare Sites。
