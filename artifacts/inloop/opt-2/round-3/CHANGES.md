# 第 3 轮：修复平台外层作用域，最终批跑

第 2 轮已经完整执行十布局各一次，全部在 tick=0 报 program_error；本轮是阶段 2 的第三轮，不重算或豁免失败轮次。未增加第四轮。

本轮生产程序只修复同一个状态作用域错误并更新版本。平台把整个学生源码包入 `async __student_main__`；第 2 轮源文件顶层布尔量属于这个函数的局部变量，而两个帮助函数声明 `global` 后转而读取模块全局，导致首次 `_opt2_patrol_enter` 就找不到名称。送货速度函数的 `globals().get` 也读错作用域。现在使用同一外层共享字典 `OPT2_MOTION_STATE`，各函数直接读取或修改字典项，并继续在 finally 中恢复旧值。

没有改变速度数值、任何距离或确认阈值、测距模型、过滤规则、道路选点、WM融合或动作策略。第 2 轮功能改动与已有数值依据仍见 [第2轮改动](../round-2/CHANGES.md)。不以离线启动测试宣称控制路线已经成功。
