# v3 阶段 0：先双球 demo，后优化

本目录记录 2026-09-23 用户的新执行方案，替代上一方案的停止状态。
旧 `stage-1/round-3` 保留原样，只作为新 demo 基线，不把旧成功局算作本次双球成功。

阶段 0 不批跑、不统计：从冻结 `wm-stage1-r3` 改为同局两次寻找、确认、抓取、送达；第二球先查 WM 记忆，没有记忆再巡逻。已送达物不得重新成为候选，可以使用公开 `mission.storage` 与运行时记忆，不读取 mission target 锚点。不改测距修正常数、确认门槛与 WM 融合；不做伪检测过滤、标定、泛化。

优先顺序 map-03、04、05、08，再尝试其余尚未执行布局；遇伪检测、侧向漏抓或道路卡点就记录后换图，不深入修图。每次只运行当前所需布局，driver 分配到其他布局时在执行前退出，不计为试过。任一局成功即结束 demo；全部十图均失败则停止，不进入优化。

成功必须来自同一局：

- 原始 record.events 中两个不同目标物都有 package_delivered，且没有撤销送达。
- program_error=0，仿真用时≤600秒。
- 两球分别为40–90cm窗口内、三个不同位置、相邻≥15cm、同一轨迹；原有最终确认点≥0.5m不放宽。
- 每球纯记忆行驶≥30cm，approach仅在WM距离≤0.25m且max_steps=1、每球≤3次。
- onRoad全程true；全局observe≤92，不通过清零计数或重置运动守卫绕过约束。
- 无运行时真值、无布局坐标、未读取 mission target 道路锚点。
- 两球抓取与送达各有关键帧，截图时刻和事件时刻分别保留；不伪造同tick相机证据。

完整日志、samples、原始record、冻结程序、版本和SHA256保存在本目录；失败地图各一行，引用原始日志数值。DEMO.md包含地图、两球时间线、第二球来源及复跑命令。报告不把单球送达或部分门槛达标当作成功。

阶段 0 通过后才进入 opt-1（过滤器+map-02回归），随后 opt-2（双球10布局）、opt-3（P2/P3验收）；各优化阶段最多三轮，完整批跑、固定独立场景合并口径及无回归门。旧附录 A–D 见 `../stage-1/ACCEPTANCE.md`，具体新阶段门槛以本次用户 v3 消息为准。opt-4 开始前须用户确认，赛题1仅能在最终阶段运行。
