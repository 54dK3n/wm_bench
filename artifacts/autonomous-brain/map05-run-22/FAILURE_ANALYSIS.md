## 失败原因与限制

直接结束原因是round_limit，并且第二球没有交付。52次动作失败分为：需要沿路换位的视觉接近失败36次、已知道路耗尽3次、遇阻后退回路口11次、在路口遇阻2次。完整失败轮次见 `run-metrics.json` 与 `report/evaluation.json`。

模型也重复选择已完成的导航子步骤。固定公开前缀审查确认r66首次到达存放区后，r67–76再次导航十次，实际请求中保留了成功到达、约34.8cm的视觉证据；WM物体表仍约42.4cm。两种距离表达和阶段完成含义可能影响决策，但没有证据证明唯一原因。该前缀未覆盖后续，不能据此宣称永久循环；本局最终在r92执行了place。证据见 `artifacts/autonomous-brain/run22-public-planner-review-20260926/REPORT.md`。

完整公开日志另核对了200/200动作后的新观测、891帧同tick传感、491次小动作前后关联及70次go_to/pick的CONFIRMED前置条件，未发现不一致。全局无移动重复导航共28次：r44–46对第一球3次，r67–91对存放区25次。定义、逐项证据与源码SHA见 `public-execution-audit.json`，可用同名Python脚本复算。

第二球从554.82秒得到确认，此后多次导航仍需道路换位，原地环视和重复导航没有完成接近。没有调低距离或确认门槛，没有用真值帮助选动作，也没有把第200轮的普通动作成功当作任务完成。最终自建记忆还有40个未探索出口；本局即使不考虑该项，也因第二球未交付而失败。
