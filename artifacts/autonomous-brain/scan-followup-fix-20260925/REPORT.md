# 扫描后继续确认候选

首局观测 64 首次获得 target_018，有效原始距离 73cm、一次命中。扫描结束后恢复相反朝向，后续两次前进把记忆距离增至约 100.5cm 和 118.4cm；全局 176 次观测仅该帧出现红球。该帧实际有两条红球检测，另一条原始距离 100cm，按原感知窗口排除，不能称只看见一个红球。逐条传感器依据和源 SHA256 见 `observed-failure.json`，未使用真值。

Actions v5 完整扫描四向后，若看到指令所指定颜色的 TENTATIVE 候选，且局部道路感知显示方向可行，便返回该实际观测朝向；持物时优先存放区。指令未指定红/蓝时不默认红球。护栏要求道路方向误差不超过 10°、前方净空至少 16cm；空值和非有限值跳过。候选的观测编号、物体 ID、朝向均进动作证据。

探索时，新鲜球/存放区候选可见则沿路步长 16cm，否则 20cm；一旦出现新 CONFIRMED 物体即结束本动作，让大模型决定下一步。原始测距窗口、三次相隔至少 15cm 的确认条件、M5 与抓放判定均未改动。原地转向不增加独立命中。
