已观测道路连接：只读设计依据

本目录固化了 Run18/19 公共脑日志中的三个具体情形。复算通过不代表修复完成，更不代表 Run20 或任何正式局通过。没有修改生产源码、默认测试、其他报告、角度／距离门限或 done 条件；没有读取真值、布局、隐藏 record、环境变量或凭据，没有联网或产生机器人动作。

冻结源码基准为 `6ee4abf464504eb297242df98dc9fadaaf7debfa`。采集时 actions.py、navigation.py、run.py、llm.py 都与该提交逐字节一致；引用和哈希分别见 [source-references.txt](source-references.txt)、[capture-manifest.json](capture-manifest.json)。复算仅导入本目录的冻结 navigation v4 副本，不导入当前生产包、桥或模型客户端。

公共输入见 [public-inputs.json](public-inputs.json)。Run18 保留 obs1–851 的最小 road／odometry 字段，以独立重建 r126 当时的轨迹图；未保存相机物体或模型请求。另保存 r109/r126 的相关状态和 motion，以及 Run19 J18/J24/J25 对应观察、相关轮次的道路记忆和已完成动作。原输入仅记录明确截止位置的原始字节前缀哈希，不把前缀哈希冒充全文件哈希。所有路径均为仓库相对路径。

**弦方向不能代替实际出口。** Run18 r126／obs851，车头绝对90.7°，当前四个fresh出口 `[179.3,89.3,-0.7,-89.9]°` 都已完成，历史U=29。按现有图的弦长权重，最近有未探索项的候选是 junction-16，路径为：

```text
(.156,.274) → (-.003,.524) → (-.002,.430) m
```

首段弦角为绝对32.456360°、相对−58.243640°，在原5°匹配条件下没有当前出口对应。该图边实际来自 r109／obs737→738：车头绝对0.8°、`take_exit(angleDeg=0)`，执行器行驶40.6cm。这个真实出发方向换算到r126是相对−89.9°，恰好唯一对应一个fresh出口。首段弦长只有29.627859cm，整条候选路径图权重39.028390cm，所以该权重也不能被称为真实已行驶长度。

这是“直接用轨迹弦角生成模型出口提示”的反例。原模型并没有收到该错误提示；其r126实际选择179.3°，不能把上述推导冒充原模型曾执行的错误角度。

**一个空间节点可以混合不同观测位置的出口集合。** Run19 r51／obs332建立J18，最初记录 `[8.9,-90,169.2]°`。r104／obs681的fresh集合为 `[-149.5,90,-11.3]°`，该位置距J18中心13.602941cm，距已有相同集合的J5中心15.620499cm，因此原最近节点规则把三项加到J18，使其变为六项。obs681–684的当前集合不包含旧−90°；r163存档中旧−90°仍visits=0、completed=false、blocked=false，确实贡献一个U。

这证明同一个空间桶不能被描述成“当前同时可见六个出口”。旧−90°原本确实被观察过，不能据此宣称它物理不存在或永久不可完成，也不能删除其义务。

**相似路口记忆仍只能称为候选。** Run19 r81／obs523的J24位置为 `(-.865,1.819)m`，r86／obs556的J25为 `(-.748,1.718)m`，相距15.456390cm，刚超过原15cm门限。两个fresh集合分别为 `[-137,125.5,18.4]°`、`[-137,125.6,18.5]°`；两个约125.5°项到r163都未访问、未完成、未阻塞。这个分裂符合当前门限，单靠位置和集合相似不能证明物理身份相同，不能直接合并后清U。

连续采样的atNode=true也不足以证明同一节点：Run18 obs1→2两端都为true，但中间take_exit实际行25cm／81 ticks，fresh集合从 `[0]°`变为 `[90,.8,-90,-180]°`。离散采样没有证明中间始终在同一个路口区域。

现有实现已经保存道路采样顶点、连续移动构成的图边、记忆节点和历史出口状态。模型状态只暴露当前出口与junction_history，没有已走路径、当前节点ID或出发出口到到达节点的连接。active_exit只暂存选择，到达后清除；图边仅保存对称的端点距离，没有出发方向、原始行程观察或有向通过证据。go_to只能接受已确认物体ID，不能被直接拿来选择历史路口；explore只选当前出口。done仍检查原U=0，未改动。
