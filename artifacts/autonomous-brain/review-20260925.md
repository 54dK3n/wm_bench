# 外部大脑独立审查（2026-09-25）

本审查覆盖 `autonomous_brain/bridge.py`、`run.py`、`navigation.py`、`actions.py`、`llm.py`，并复核离线评测器。没有运行真实大模型任务，也没有得到 map-05 成功局；假模型传输联调不能替代任务验收。除审查发现后获准修复的 LLM 异常记录分支外，没有修改被审查代码。

## 理想执行路径的阻断

近距离重见仍被当成漏检，可能使 `go_to → pick` 断开。感知适配器只将原始测距 40–90cm 的球检测送入确认流程；接近到 25–40cm 时即使相机持续看见目标，也可能因当前视野内的漏检衰减而变为 STALE。下一轮 LLM 和 `pick` 都只接受 CONFIRMED，因此到位成功不能保证抓取动作合法。

该问题已交给感知代理修复：仅对双向唯一关联、此前已确认的近距重见刷新可见时间，保留位置、置信度、状态和命中数，不修改上游 WorldModel、M5 或三次独立观测门槛。本审查没有重复其修复或声称真实抓放已通过；最终状态应以该修复的测试和后续真实任务日志为准。

## 失败恢复限制

`place` 在夹爪已空但像素证据未确认球位于存放区时，会将旧对象保留为 `RELEASED_UNVERIFIED`，清空持物身份，并返回失败。这一处理不会把未证实的放置记为送达。

当前动作集合没有恢复该旧身份的路径：`go_to`、`pick` 要求 CONFIRMED；`mark_picked` 拒绝 RELEASED_UNVERIFIED；`mark_delivered` 要求 HELD；`done` 又拒绝尚未 DELIVERED 的红球。因此一次投放后视觉假阴性可使后续观测或对新轨迹的重新抓放无法解除旧记录，最终保守失败。这属于失败恢复限制，不是从未发生失败时的必然阻断；本轮按要求不扩展恢复功能，仍须保留证据和失败原因，不能声称已完成任务。

常规动作返回和前置条件失败都会经过新的结束观测。执行器或传输抛异常时，主循环则记录错误并停止；此分支不能笼统声称已经完成动作后的观测判定。若连接或平台已经停止，无法取得后观测本身应作为证据缺失说明，而不能以执行器结果推断成功。

## LLM 日志和回放

审查用禁止联网的异常 fixture 复现了一个日志缺口：`http.client.IncompleteRead` 原来未被捕获，发起一次请求后会出现已记录调用数为零、日志为空。该问题已在 `autonomous-brain-llm/v2` 修复：

- HTTP 协议异常记录异常类型，存在 partial bytes 时以 UTF-8 replacement 解码保存。
- HTTP 错误响应体读取中断仍保留原 HTTP 状态及读取异常类型。
- 异常后立即停止，不增加网络重试或改变模型参数。
- v1/v2 transcript 均可离线读取；回放保留源记录版本，代码版本由源文件 SHA256 单独标识。

`python3 -m pytest tests/test_brain_llm.py -q`：48 项通过，包括中断响应的日志与无网回放、HTTP 错误体中断、协议错误及 v1 回放兼容。纯离线 fixture 未调用真实模型。

现有正常输出回放按完整请求和请求 SHA256 匹配，并重新解析与校验动作；不读取 API 凭证或发起模型网络请求。两个非法输出后停止，成功输出不以模型自报的动作执行结果作为物理成功依据。

## 上限与验收

主循环最多执行配置的 200 轮；恰到上限仍保持 failed，不接受该轮的 done 覆盖上限。动作前后检查仿真时间，平台还执行 1200 秒硬上限。离线评测独立读取 record 的结束 tick 计算时长，要求轮数和时长严格小于上限；大脑错误、模型错误或超限不能被真值交付覆盖为通过。

真实网络断开或平台达到硬上限可能使脑侧最后保存的时间滞后；最终验收的仿真时长以原生 record 为准。并未发现允许脑进程调用非白名单接口、读取布局坐标或将真值交给模型的新路径。
