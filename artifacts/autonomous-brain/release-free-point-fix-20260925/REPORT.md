# 放置前选择观测空位候选

第14局实际双球送达，但放置后只见旧球的单个红色连通框；第一个换位诊断完整严格回放75轮/90条记录，新增一个15.940812099cm视点仍无独立新球见证，诊断失败。离线评测进一步发现两个球被平台堆叠，不能假定水平换位必然使连通框分离。旧局及旧判定不改写。

Actions v17 在place开始时，若相机当前识别出旧已送达红球，才选择释放瞄准点。它从当前唯一最大、四边均在画面内的绿色分量bbox取左右四分之一横向位置及中间纵向位置；这些点在原内椭圆内。用当前红球、蓝球和障碍框向外各扩半个自身宽高排除占用候选，再选离占用框相对最远的候选，平局固定取左。候选来自bbox几何推断，不能证明逐像素绿色或实际无物。

使用现有公开相机参数作像素到地面投影，再用当前里程计变换为固定地面目标。接近期间仍每步观测、要求看见绿色区域，但不因绿色框被旧球遮挡或裁切而漂移目标。原19cm/3°对准门槛、八次最多7cm平移、每段最多三次转向预算不变。瞄准目标与最后对准距离/方位另记入release_aim，明确为固定观测地面点加里程计推算；不伪装成绿色中心传感读数。

没有旧交付球时沿用原流程。无完整唯一绿色分量、无支持的候选、投影无效或接近时失去绿色观测，均保留持物并报失败，不释放。放后仍由原holding=false、完整绿色区域、椭圆0.64、非旧且唯一新球见证判定；选择候选本身不证明送达。v16有限换位核验保留，所有身份护栏不变。

源码不读取平台堆叠阈值、任务、布局、真值或评测数据。平台堆叠解释仅供离线失败分析；不是大脑输入。WorldModel官方依赖、M5、确认门槛、模型参数、正式200轮/1200秒上限和独立评测均不变。
