# Stage-two topology acceptance scope, registered before implementation and formal runs

The completed reliability prerequisite gate passed 1045 Python and 28 Node
tests. Stage-two work starts only after that gate. No current formal task has
started. This definition is fixed before observing any current formal result.

The task is exactly `把地图上的红球都送到绿色存放区`, with no quantity supplied
to the brain. The known-two-ball regression keeps its quantity-based completion
and does not acquire a whole-map exploration obligation.

The true-node denominator includes **all** nodes formed by grouping the first
and last endpoint of every road in the frozen record's `ruleDefinition.roads`,
under the platform's six-decimal endpoint rounding and negative-zero
normalization. Degree-one ends, degree-two connectors and higher-degree
junctions all count. Interior polyline points do not. Nodes with no permitted
outgoing exit still count. No reachable-region subset is substituted.

The brain-node numerator counts its semantic node identities in the same scope,
after only evidence-backed aliases. Raw observation anchors and intermediate
trajectory samples are not extra nodes. Unresolved hypotheses cannot silently
disappear from the reported count. The independent evaluator reports the ratio,
duplicate identities, false merges, missing true nodes and unresolved nodes or
connections separately. Ratio <= 1.2 is necessary but insufficient: missing
nodes, false merges, unresolved identities/connections and uncovered permitted
directed exits must each be zero.

Public-sensor validation independently joins bridge observations, exact frames,
odometry and actual motion windows. Every observed `atNode=true` anchor must be
accounted for, including a node with no exits. An accepted command, passing a
waypoint or a stored `completed` boolean cannot prove traversal. A reverse
route that may be attempted does not prove the reverse direction was travelled.
Temporary blocked exits remain pending. Fresh frames alone do not resolve a
failed route or ambiguous identity.

Truth is read only in the evaluator to rebuild topology, check anchor/traversal
correspondence and verify coverage. It never enters the brain or its model
state. Task acceptance additionally requires all required physical targets
delivered, all discovered target obligations resolved, an empty gripper, and
actual model `done` followed by fresh completion checks and strict transcript
verification. Ten-layout and hardware stages remain closed.
