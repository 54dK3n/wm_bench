# 放置后有限换位观测修复

第14局独立评测为真实2/2送达，但第二次place只检测到一个匹配旧已送达身份的红框，无法证明新球已放入；整体FAIL。原判定不追溯修改，也不借评测真值补判。

Actions v16仅在空夹爪、初次退后核验无新球见证、当前同类球检测非空且全部明确匹配旧已送达身份时，先完成原实测路径归路，再最多追加两个道路视点。每个视点最多四次4cm平移，每步重新观测，使用当前道路轴、前方和侧方净空，并检查实际里程计。路口转向后按原5°规则重新唯一匹配所选出口；方向不明、受阻、离路或无进展即停止，离路只沿本次实测轨迹归路。

以初次观测中具有有限位置的唯一最大完整绿色分量瞄准；绿色像素碎片不合并、不当作多个存放区。认证仍使用当前所有球与所有绿色分量的原唯一像素见证规则，完整区域及椭圆0.64门槛不变。原释放帧、时刻与释放前身份集合固定。追加视点还要求初次所见旧交付身份在同一帧仍各自可识别，才能将额外的唯一非旧框视为新球证据；单一未知框也不能通过。仍无法验证则标为RELEASED_UNVERIFIED。

Runtime v8在下一轮紧凑状态保留追加观测原因、旧身份是否仍可见、所需与所见身份、视点数量及独立归路结果。原归路与后续归路的帧和成败不覆盖。没有追加观测时原紧凑结构不变。

未修改WorldModel、M5、原CONFIRMED前置条件、三位置确认、抓放次数、模型参数、正式200轮/1200秒上限、平台或独立评测门槛。

## 核验

- 新放置回归30项，与旧归路测试共48项通过；v15基线对照18项失败、12项通过，表示旧版缺少此行为，不代表18个独立缺陷。原始输出保留在`independent-reobservation-*-v2.*`；v1历史也保留。
- 新紧凑状态回归5项，验证不同归路帧、后次失败可见、单一候选因旧身份缺失而拒绝、未知字段隔离和复制独立性。
- 全部520项大脑测试通过，见`integrated-tests-v2.txt`与`integrated-tests-v2.json`；运行前后源码哈希相同。
- 只读独立审查发现并修复多绿色碎片选点、转后出口复核、后次归路证据丢失、旧球匹配丢失后的单框误认风险；当前仍可能因遮挡不足而合法失败，不承诺换位必然分离检测。
- `run14-first75-llm.jsonl`仅逐字节选取原第14局decision_index≤75的90条调用，来源与SHA见`replay-prefix.json`。严格输入匹配的前75轮仿真诊断尚待运行；不调用模型API、不作为正式成功局。
