# 主动确认采样修复轮

起点与远端核对：`69376055870d430a6b82db971eb9607309cfdb3d`，分支 `codex/autonomous-brain`，工作区干净。历史 d1538f7 阶段1 PASS、本轮之前1117336候选 FAIL 均保持。

本轮只修主动确认采样、短段聚合、候选截断前过滤、探索结果语义及有界发现摘要。仍为六种高层动作，通过明确版本化的 `explore(discovery_id=...)` 请求采样；TENTATIVE 不能直接 go_to/pick。使用公开相机、里程计、局部道路及自建道路证据，不读评测真值，不改平台权限、WorldModel依赖或原确认/抓放门。

先复现函数反例，再验证真实 Perception→动作→再次Perception 的足够独立位姿正对照及越窗、遮挡、曲路、重复位置、竞争身份等反例。记录测试集合和实际命令，旧转录按其原版本回放。未取得新外部探针附件时按用户列出的明确输入独立复现，不改探针指纹。

联合前置通过后冻结一个候选，以 DeepSeek Flash、temperature=0、thinking disabled、200轮/1200仿真秒，在map-05运行已知两个红球任务一局。失败则保留全部证据、定位首个实质阻塞并停止；只有此候选阶段1通过才进入既定阶段2顺序。正式最多两局，不循环调参重跑，不做十布局或硬件。

本轮原始日志仅Release附件；Git只保存源码、测试、摘要、指标、哈希和恢复入口。冻结源码与报告分提交正常推送，推送后重新读远端完整SHA。
