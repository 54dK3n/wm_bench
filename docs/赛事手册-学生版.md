# 广阳岛人工智能竞赛平台赛事手册（学生版）

> 本手册用于帮助参赛学生快速了解比赛内容和平台使用方法。比赛时间、场次安排、设备要求及最终裁定，以组委会发布的正式通知为准。

## 一、比赛简介

比赛包含两个赛题：

- **赛题一：广阳岛智能车**。参赛队通过 Python 代码或 Blockly 积木控制智能车，在广阳岛三维地图中完成运输、巡检和避障任务。
- **赛题二：识物工坊**。参赛队采集图片、训练“橙子 / 非橙子”图像分类模型，并提交模型接受后台评测。

比赛分为小学组、初中组和高中组。成绩按队伍计算，同一队伍可以有多个学生账号。

## 二、赛题与成绩组成

| 比赛内容 | 主要任务 | 占总成绩 |
| --- | --- | ---: |
| 智能车任务1 | 基础路线、物体搬运与避障 | 25% |
| 智能车任务2 | 更多途径点、物体和障碍 | 25% |
| 智能车任务3 | 路线更长、综合难度更高 | 25% |
| 识物工坊 | 训练并提交橙子识别模型 | 25% |

四项合计满分 100 分。没有正式提交记录的项目按 0 分计算；智能车任务即使没有全部完成，也会按已经完成的任务内容计算单次成绩。

## 三、赛题一：广阳岛智能车

### 1. 任务目标

三个任务使用相同的广阳岛道路底图，但任务规模、物体数量和点位配置不同，难度逐步提高。小车需要根据任务要求：

- 按编号顺序通过途径点；
- 抓取目标物并送到目标点；
- 把混淆物移出道路；
- 避开指定障碍物；
- 完成其他目标后返回起点。

地图道路按约 5 米 × 3 米的实际比例设计，移动距离以厘米为单位。场景中红色包裹是目标物、蓝色包裹是混淆物、绿色区域是目标点，岩石是需要避开的障碍物。

| 任务 | 途径点 | 目标物 | 混淆物 | 指定障碍物 |
| --- | ---: | ---: | ---: | ---: |
| 任务1 | 4 个 | 1 个 | 1 个 | 1 个 |
| 任务2 | 6 个 | 2 个 | 2 个 | 2 个 |
| 任务3 | 8 个 | 3 个 | 3 个 | 3 个 |

途径点必须按 1、2、3……的顺序通过。提前经过后面的途径点不会计入进度，完成前一个途径点后还需要重新经过该点。

目标物在程序结束时仍需完整留在目标点内。碰撞指定障碍物后，该障碍物的避让任务分在本次运行中不能恢复；避障任务也可能在其他目标完成后才统一确认。

三个任务使用相同的道路网络和评分方式，单次任务最长 600 秒；难度主要通过增加途径点、物品和障碍物数量逐步提高。

### 2. 编程方式

每队可以自由选择以下任一种方式，也可以在两种方式之间切换：

- **Python**：直接编写程序，可使用小车移动、转向、夹爪、导航传感、道路控制和摄像头感知等指令。
- **Blockly**：通过积木搭建程序，可使用移动、判断、循环、变量、函数、传感和道路控制等积木。

Python 和 Blockly 使用相同的任务地图和评分规则。同一任务会取全队所有成员在两种方式中的最高正式提交成绩，不需要重复完成两遍。

### 3. 地图分配

任务1、任务2、任务3分别设有 8、10、12 套地图。系统会按照队伍为三个任务各分配一套地图；同队成员看到相同地图，不能自行更换。不同队伍可能得到不同的物体、途径点和障碍物位置，因此程序应尽量使用观察、判断和规划，而不是直接照搬其他队伍的固定路线。

### 4. 单个任务如何评分

每个智能车任务满分 100 分，主要包括：

- 任务完成：40 分；
- 道路与碰撞规则：25 分；
- 程序自主运行：15 分；
- 完整完成后的效率：20 分。

驶出道路、在道路外停留或发生碰撞都会扣分。模拟器中的“实时评测”只用于调试参考，正式成绩以后台保存并重新计算的结果为准。

## 四、赛题二：识物工坊

### 1. 任务目标

训练一个能够判断整张图片属于“橙子”还是“非橙子”的分类模型。本赛题不要求在图片中框出橙子的位置。

### 2. 基本流程

1. 进入“识物工坊”，新建橙子识别比赛项目。
2. 分别为“橙子”和“非橙子”上传图片，或使用摄像头采集样本。
3. 每类至少准备 5 张图片；建议准备 20 张以上，并尽量让两类数量接近。
4. 点击“开始训练”，训练过程中保持页面开启。
5. 使用没有参与训练的新图片进行测试；发现误判后补充样本并重新训练。
6. 点击“下载训练模型”，得到参赛模型 ZIP。
7. 进入“比赛提交”，选择模型 ZIP 并确认提交。

橙子样本应包含不同角度、距离、光线和背景；非橙子样本可加入橘子、苹果、橙色物品、手、桌面和空背景等容易混淆的画面。

### 3. 提交与评分

- 每队可以多次提交，但**只以截止前最后一次提交为准**。
- 最后一次提交即使模型损坏、类别错误或格式不符合要求，也会替代上一份模型并按 0 分记录，因此提交前要确认模型 ZIP 完整、可以正常使用。
- 应直接提交训练台导出的模型 ZIP，不要解压、修改或重新压缩；模型包不得超过 2 MiB。
- 后台使用保密图片评测，成绩综合“橙子识别正确率”和“非橙子排除正确率”，两类各占一半。
- 学生端只显示提交回执，不显示保密测试图片、错误明细和正式评测分数。

训练图片、项目和模型主要保存在当前浏览器中，不会跟随账号自动转移到另一台电脑。换设备或清理浏览器数据前，请先下载“项目备份”。“项目备份”和“训练模型”用途不同，比赛提交时应选择训练台导出的模型 ZIP。

## 五、账号与队伍

如果组委会安排从比赛官网进入，账号、队伍和组别会自动带入，无需在本平台重复注册。以下步骤仅适用于组委会开放本地注册的情况。

1. 按组委会提供的地址打开统一比赛平台。
2. 已有账号直接登录；没有账号时进入注册页面。
3. 第一名队员选择“创建新队伍”，填写队伍名称和参赛组别。
4. 创建成功后保存 8 位队伍邀请码，并发给同队成员。
5. 其他队员注册时选择“使用邀请码加入队伍”，不要重复创建同名队伍。

用户名必须唯一，密码至少 10 位。队伍名称也不能和已有队伍重复。加入已有队伍后，参赛组别会自动继承该队伍设置。

登录后，右上角“队伍邀请码”可以再次查看邀请码。邀请码只应发给本队成员，不要公开发布。

## 六、平台使用流程

### 智能车任务

1. 在统一首页进入 Python 或 Blockly。
2. 选择任务1、任务2或任务3。
3. 编写代码或连接积木。
4. 点击“运行代码”，观察小车状态、任务进度和实时评测。
5. 根据结果修改程序，可以多次运行调试。
6. 打开“我的比赛记录”，选择满意的记录进行“正式提交”。

每次开始运行时，小车、物品和任务进度都会恢复到本队当前地图的起始状态；手动调整过的观察视角会保留，便于连续调试。

普通运行和自动保存的调试记录不会进入正式排名。只有点击“正式提交”的记录才会成为比赛成绩；所有正式提交记录都会保留，最终计分时分别取队伍在三个任务中的最高正式成绩。

### 识物工坊

1. 在统一首页进入“识物工坊”。
2. 完成样本准备、模型训练和新图片测试。
3. 下载训练模型后进入“比赛提交”。
4. 上传模型 ZIP，看到提交成功回执后再离开页面。

## 七、比赛注意事项

- 比赛前确认自己登录的是正确账号和队伍。
- 不要把账号密码或队伍邀请码交给无关人员。
- 调试时关注途径点顺序、碰撞和是否驶出道路，不要只看小车是否到达终点。
- 正式提交前再次检查任务、地图和分数；智能车取最高正式成绩，识物工坊取最后一次提交。
- 不要刷新、关闭正在训练或正在提交的页面。
- 识物项目保存在当前浏览器，建议定期下载项目备份。
- 摄像头需要浏览器授权；无法使用时可以改为上传图片。
- 识物工坊第一次训练需要加载约 8 MB 的基础模型，首次进入可能稍慢；比赛前应先确认浏览器可以正常训练。
- 禁止复制其他队伍的程序、积木或模型，比赛应由本队独立完成。

## 八、常见问题

### 经过途径点为什么没有加分？

请检查是否按编号顺序通过。只有当前要求的途径点会计入进度。

### 点击运行后为什么没有正式成绩？

运行只会生成调试记录。请在“我的比赛记录”中选择记录并点击“正式提交”。

### Python 和 Blockly 的成绩会分开计算吗？

不会。同一任务会取全队在 Python 和 Blockly 中的最高正式成绩。

### 为什么识物工坊看不到正式分数？

识物工坊使用保密测试集。学生端只显示是否提交成功，正式分数和评测明细由管理员后台查看。

### 换电脑后识物项目为什么不见了？

训练项目默认保存在原设备的浏览器中。需要换设备时，应先导出项目备份，再在新设备导入。

## 九、成绩确认

统一首页会显示智能车三个任务的队伍最高成绩，以及识物工坊是否已经提交。比赛结束前请逐项确认：

- 任务1已有正式提交；
- 任务2已有正式提交；
- 任务3已有正式提交；
- 识物工坊已有提交成功回执，并已在提交前确认模型文件正确。

如页面显示、队伍信息或提交记录存在异常，请停止重复操作并及时联系现场老师或赛事管理员。
